## 关于"注入时物体仍在运动"

163 条（修正后 164 条）有效注入中，部分在注入时物体仍有速度与接触，**这不是时机错误**：

| 触发事件 | 非"干净释放" |
| --- | --- |
| `enter_first_subgoal_completed`（early） | 0 |
| `enter_next_subgoal_approach` / `post_completion_retreat`（mid） | 0 |
| `enter_next_subgoal_lift` / `x3a_actuation`（later） | 全部 |

`later` 的定义就是"s2 已抓起该目标"，物体必然在被操作 —— 正是规则要求的
「在执行 s2 的过程中回滚 s1」。early 与 mid 100% 落在「已释放并静止」，证明 s1
完成判定的修复有效。
