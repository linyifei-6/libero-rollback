# 姿态机制审核指南

## 一、报告里的角度怎么读

卡片上的欧拉角是把**写入的四元数**换算成 roll / pitch / yaw，是**世界坐标系下的绝对姿态**，
不是"相对旋转了多少"。

四元数按 LIBERO / MuJoCo 约定为 `[w, x, y, z]`，换算：

```
roll  = atan2(2(wx+yz), 1-2(x²+y²))      # 绕 x 轴
pitch = asin(2(wy-zx))                    # 绕 y 轴
yaw   = atan2(2(wz+xy), 1-2(y²+z²))      # 绕 z 轴
```

例：`[0, 0, 0, 1]` → roll 0° / pitch 0° / yaw 180°，即**绕世界 z 轴转 180°**。

## 二、任务 01 的 roll 0 / pitch 0 / yaw 180 代表什么

它表示"黑碗的**局部 x 轴**绕世界 z 轴转了 180°"，**不是**"碗翻转了"。
roll 与 pitch 都是 0，说明碗的**底面朝向完全没变** —— 仍然平贴桌面。

所以你在视频里看到"黑碗回滚后平放在桌面上"**与数据完全一致**，没有矛盾。

### 更关键的问题：这个用例其实是退化的

碗是**绕竖直轴旋转对称**的物体（`akita_black_bowl` 只有一个 `*_vis` 网格、无把手等特征）。
对它绕世界 z 轴转 180°：

* 视觉上**完全相同**（对称操作）；
* `In` 谓词只看包含与接触，与朝向无关 → **关系必然保持为真**。

**结论：任务 01 的偏航用例既测不出视觉差异，也测不出关系变化，两条信息都是零。**
它标记为"对照（关系保持）"在技术上没错，但没有诊断价值。应替换为：
绕水平轴（roll/pitch）的旋转 —— 那会改变底面朝向、影响接触，从而可能真正翻转 `In`。

## 三、04 的两条为什么是有效的

任务 04 写入的姿态是 `[-0.5055, 0.5094, 0.4944, 0.4904]`（roll −104.6° / pitch −88.2° /
yaw +14.6°）与 `[-0.0145, 0.0039, 0.9668, 0.255]`（roll +150.4° / pitch −1.7° / yaw +180°）。
两者都**实质改变了罐子的朝向**（含明显的 roll/pitch 分量），因此：

* 画面里能看到变化；
* 汤罐的 `In(basket)` 关系确实由真变假。

你的判断正确 —— 04 的两条是有效用例。

## 四、审核建议的逐条方法

| 步骤 | 看什么 | 判断标准 |
| --- | --- | --- |
| 1 | 视频里注入前后**物体姿态**是否变化 | 变了才说明姿态写入生效 |
| 2 | roll / pitch 是否非零 | 两者都为 0 时，物体底面朝向未变，通常不会有实质失效 |
| 3 | 卡片的"s1 关系"列 | 与视频里物体是否真的离开目标区域/容器一致 |
| 4 | 注入步与基线步数 | 注入应发生在基线完成之前；基线失败则该条不可用 |
| 5 | 被拒用例的原因 | `ROLLBACK_PATHOLOGICAL_PENETRATION` 属几何约束，不是缺陷 |

**核心判断**：旋转是否改变了"物体相对于目标区域的关系"。绕竖直轴转对称物体 = 什么也没发生。

## 五、已发现的三个需要修正之处

1. **任务 01 的偏航用例退化**（见第二节）。需改为绕水平轴的旋转，或换用带可见朝向特征的物体。
2. **请求的旋转量与写入姿态不成简单对应**。`orientation_delta` 是与**目标位姿**复合，
   不是绕当前姿态旋转。任务 01 请求 z 轴 90°，写入的是 z 轴 180°，说明复合基座不是"当前姿态"。
   **含义**：用例不能按"转了多少度"来设计失效强度，必须按**写入后的绝对姿态**校准。
3. **缺少 `pre_orientation_wxyz` 记录**。观测里只有写入后的姿态，没有注入前姿态，
   因此**无法从数据验证"实际施加了多大的相对旋转"**。建议让处理器在注入前记录该字段
   （观测里已有 `pre_position`，姿态缺对应项）。

## 六、下一步建议

* 把姿态用例的角度改为**绕水平轴**（roll 或 pitch），例如 roll 60°/90°，任务是让底面离开支撑；
* 用"写入后的绝对姿态"作为设计变量，先用小角度试探，记录谓词是否翻转；
* 每个容器分别校准可用角度（抽屉与盘子 60° 会穿透，篮子可以）；
* 保留偏航用例作为**显式退化对照**，并在标签里写明"对称旋转，预期无变化"，不要当作有效失效方向。
