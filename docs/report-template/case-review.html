审核卡要素（每张卡片固定 4 个区块）

  • ① 注入有效性：注入前关系真、注入后关系假（C0 保持真）、无穿模、零速度、已释放；restorable 只作辅助，不是模型恢复。
  • ② 恢复有效性：relation_final / recovered / restored_at_step / notice_latency / repair_budget_steps；C0 与未触发写 N/A。
  • ③ 视频证据：三个跳转按钮使用 video.currentTime；正式报告加载 videos/<case_id>.mp4，缺失时显式提示。
  • ④ 人工审核：“注入有效”“恢复有效”两个勾选 + 备注，实时保存到 localStorage，可导出 JSON。
