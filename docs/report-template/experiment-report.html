{{METRIC_DEF_TABLE}}

口径红线

  1. Recovery 分母 = 注入有效且非 C0；C0 对照、注入无效、触发未到达一律不进分母。
  2. 不可触发 = N/A，不是 0%；N/A 单独计数，并进表格与结论。
  3. restorable oracle 只证明几何可修，不等于策略自修复，不进恢复分子。
  4. 每个率给 Wilson 95% CI 与 k/N；分母为 0 时写 N/A，不得显示 0.0%。
  5. 数字只从 aggregate.json 取；页面 KPI、表格、正文、JSON 四处必须一致。
