# 任务 01 与任务 03 扰动用例逐条表

> **历史记录（勿按当前 catalog 解读）**：本文记录 任务 01–03 用例表 的实验，其中的用例总数（含 pulse 行）与逐条数字均为**当时口径**。2026-10-16 起 `progress-pulse-*`（24 条）已退出数据集（理由见 `archive/pulse-descoped-20261016/README.md`），当前 catalog 为 **288 条**。本文的数字未改写，以保证历史结论可追溯；需要当前口径时以 `docs/case-matrix-current.md` 与 `dataset/current/manifest.yaml` 为准。

本文以表格逐条列出 LIBERO-10 任务 01（把黑碗放进柜子底抽屉并关上，共 41 条）与任务 03（把两个摩卡壶放到炉灶上，共 36 条）的全部 rollback 扰动用例。每条给出扰动时机、回滚位置、回滚姿态，以及评测所需的语义与特别约束。

## 口径说明

- **扰动时机**＝用例声明的任务窗口、它对应的原生里程碑事件、以及触发到注入之间的控制步数（延迟）。
- **回滚位置**＝注入把目标物体放到哪里。位移系列的数值是相对 episode 初始位姿的带符号向量；负号一侧在原生坐标系中朝向机械手、正号一侧远离，全部贴着支撑面水平移动。
- **回滚姿态**＝注入是否改变物体朝向。绝大多数用例不改变朝向；姿态探针是唯一主动旋转的一族。
- **评测语义**＝`要求失效`（注入后关系必须为假，模型负责恢复）、`关系保持对照`（预期仍为真，不进恢复率分母）、`真值探针`（不预设结论，只读原生真值后分类）。
- **回滚目标**：两个任务都只撤销**真实执行顺序中第一个被确认完成的子目标**。任务 01 是黑碗进入抽屉区域；任务 03 是第一个摩卡壶落在灶面区域。
- 表中"来源"列：`battery` 为 rollback-battery 1.6.0，`two-subtask` 为 two-subtask-expansion 1.6.0，`above` 为 runtime-validated-above 1.6.0，`grid` 为 runtime-grid 1.3.0，`progress` 为 progress-failure 1.8.0。
- 表中 case_id 为节省宽度省略了 `libero-10-` 前缀；`...NN-` 中的 `NN` 即任务号。
