# two-subtask validation set

The agreed scope: every LIBERO-10 task here has two subtasks, so a rollback revokes
the completed s1 while s2 is being executed. Task 09 (`t276`) has a single goal and is
excluded by agreement.

Contents, all engine-valid:

* `early/p1` — one case per task (00-08): early window, original pose, 9 cases
* `matrix-v3` — tasks 04/05/06/08 x 3 windows x 3 positions, 36 cases

Reference sets not generated here because they already exist in the runtime repo:
tasks 01/02/03/07 use the RB1-RB4 bindings.
